# Sobia's Beauty Saloon — concept website

A responsive, single-page concept preview for a potential salon client in Gujar Khan.

## Preview status
This is a proposal/demo, not an owner-approved official website. Confirm the business name styling, exact address, phone/WhatsApp number, service list, opening hours, pricing, team details and salon-owned photos with the owner before public launch.

The current imagery is illustrative stock photography and is explicitly labelled as inspiration. No testimonials, awards, prices or credentials are fabricated.

## Tech
- Semantic HTML
- CSS (responsive layout)
- Vanilla JavaScript
- No build step or paid dependency

## Deploy
Can be deployed as a static site on Vercel or any static hosting provider.
